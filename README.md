# ATM-System-cpp

A console-based ATM system developed using C++ to practice object-oriented programming concepts, functions, structures, vectors, and file handling.
✨ Features
Client Management: Manage client account information.
Secure Login: Authenticate clients using account numbers and PIN codes.
Quick Withdrawal: Withdraw predefined amounts quickly.
Normal Withdrawal: Withdraw custom amounts subject to validation.
Deposit: Add funds to client accounts.
Balance Inquiry: View account balances.
File Handling: Store and update client information in a text file.
Data Persistence: Save account changes between program executions.
🛠️ Technologies Used
C++
Structures (struct)
Functions
Vectors (std::vector)
File Handling (fstream)
Input Validation
String Manipulation
